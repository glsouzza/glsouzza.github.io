# Portfólio — Gabrielly Luiza

🌐 **Acesse:** https://glsouzza.github.io

Site pessoal estático (HTML + CSS puro, sem dependências), publicado com GitHub Pages.

## Como atualizar

Edite o `index.html` direto aqui no GitHub (ícone de lápis) e salve com *Commit changes*.
Em 1–2 minutos a nova versão estará no ar.

- Novo projeto: copie um bloco `<article class="project">…</article>` na seção Projetos.
- Nova experiência: copie um bloco `<div class="item">…</div>` na seção Experiência.
- Foto: envie `foto.jpg` para o repositório e adicione `<img src="foto.jpg">` no topo.
- O tema claro/escuro segue automaticamente a configuração de quem visita.
